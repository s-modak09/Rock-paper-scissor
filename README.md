# Rock Paper Scissors

A simple Rock Paper Scissors game developed for Android using **Kotlin** and **Android Studio**. The player competes against the computer by choosing Rock, Paper, or Scissors.

## Download

[Download APK](https://github.com/s-modak09/Rock-paper-scissor/releases/tag/v1.0.0)

## Features

* Play Rock Paper Scissors against the computer
* Rock, Paper, and Scissors options
* Automatic result calculation
* Simple and user-friendly interface
* Play multiple rounds
* Lightweight Android application

## How to Play

1. Open the application.
2. Select **Rock**, **Paper**, or **Scissors**.
3. The computer makes its choice.
4. The result is displayed on the screen.
5. Play again for another round.

## Game Rules

| Player      | Computer    | Result      |
| ----------- | ----------- | ----------- |
| Rock        | Scissors    | Player Wins |
| Paper       | Rock        | Player Wins |
| Scissors    | Paper       | Player Wins |
| Same Choice | Same Choice | Draw        |
