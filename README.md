## 🎯 How to Play

1. Launch the application.
2. Choose one of the three options:

   * ✊ **Rock**
   * 📄 **Paper**
   * ✂️ **Scissors**
3. The computer makes its choice.
4. The app compares both choices.
5. The winner is displayed on the screen.
6. Play again for another round.

### 🏆 Game Rules

| Player      | Computer    | Result      |
| ----------- | ----------- | ----------- |
| Rock ✊      | Scissors ✂️ | Player Wins |
| Paper 📄    | Rock ✊      | Player Wins |
| Scissors ✂️ | Paper 📄    | Player Wins |
| Same Choice | Same Choice | Draw        |

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have:

* Android Studio installed
* Android SDK installed
* A physical Android device or Android Emulator
* Internet connection for Gradle dependency synchronization

### Installation

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project in **Android Studio**.

3. Allow Android Studio to sync the Gradle files.

4. Connect an Android device or start an Android Emulator.

5. Click **Run ▶** in Android Studio.
